# Quiz Somfy · Felgueiras

Prototipo interactivo del quiz Somfy (12 preguntas, validación inmediata, resultado por bloque).

## Contenido
- `index.html` — prototipo completo en un único archivo (fuentes, imágenes y formas incrustadas; funciona sin conexión).
- `.nojekyll` — evita que GitHub Pages procese el sitio con Jekyll.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (p. ej. `somfy-quiz`).
2. Sube el contenido de esta carpeta a la raíz del repositorio (rama `main`).
3. En el repositorio: **Settings → Pages → Build and deployment**.
   - Source: **Deploy from a branch**
   - Branch: **main** · carpeta **/ (root)** → **Save**
4. En 1–2 minutos estará disponible en `https://<usuario>.github.io/somfy-quiz/`.

## Notas
- El panel de navegación QA está oculto en esta versión.
- Las imágenes de las preguntas son provisionales, pendientes de las fotos del cliente.
